# Données : théophylline (jeu « Theoph »)

Fichier : `theoph.csv` (132 lignes, 12 patients × 11 prélèvements).

| Colonne | Signification | Unité |
|---|---|---|
| `Subject` | numéro du patient (1 à 12) | |
| `Wt` | poids du patient | kg |
| `Dose` | dose de théophylline prise par voie orale | mg/kg |
| `Time` | temps écoulé depuis la prise | h |
| `conc` | concentration de théophylline dans le sang (sérum) | mg/L |

**Source.** Boeckmann A. J., Sheiner L. B., Beal S. L. (1994). *NONMEM Users Guide, Part V*. NONMEM Project Group, University of California, San Francisco. Étude du Dr Robert Upton. Ces données sont distribuées librement avec le logiciel R (`datasets::Theoph`) ; ce fichier en est une copie au format CSV.

La présentation utilise le **patient 11** (65 kg, 4,92 mg/kg).
